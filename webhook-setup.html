Step-by-Step Setup Guide

1

Log into Easebuzz Portal

Go to the official Easebuzz Merchant Dashboard and log in with your primary merchant credentials.

2

Navigate to Webhook Settings

Click on Settings on the side navigation bar, then select Webhook Settings.

3

Register the Endpoint

Click Add or Edit Webhook, choose the trigger events (e.g. Payment Success, Payment Failure), and paste the copied URL above into the Webhook URL input.

4

Secure Signature Verification Active

Our server-to-server webhook endpoint dynamically executes a cryptographically secure SHA-512 reverse hash validation to authenticate every single request received from the Easebuzz server before confirming the order status.
