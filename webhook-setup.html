Dynamic Webhook Endpoint URL

Copy the production URL below and insert it into your PhonePe merchant developer console or provide it to your account manager.

https://new-yatri-luggege.vercel.app/api/webhook

Step-by-Step Setup Guide

1

Log into PhonePe Business Portal

Go to the official PhonePe Business Dashboard and log in with your primary merchant credentials.

2

Navigate to Developer Settings

Click on Developer Settings on the sidebar menu, then select Webhooks / Callback Configurations.

3

Register the Endpoint

Click Add New Webhook, select the transaction state changes (e.g. PAYMENT_SUCCESS, PAYMENT_ERROR), and paste the copied URL above into the Endpoint input.

4

Dynamic Connection Header Enabled

Our payment system automatically sends the X-CALLBACK-URL header containing this endpoint directly in every PhonePe V2 Checkout transaction request to ensure optimal connection redundancy.
